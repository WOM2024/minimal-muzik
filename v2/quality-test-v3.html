YouTube Kalite Test v3 – Büyük ekran + buton

Video: EQyuKThNXwk · Her yöntem ~960px genişlikte · Butonlarla kalite denemesi

Nasıl test: Her bölümü oynat → dişli menüsünden mevcut kaliteye bak → alttaki butonlara bas → tekrar dişli menüsüne bak, değişti mi not et.
Mümkünse http://localhost ile aç (file:// değil).

1. Standart (nocookie)

Kontrol grubu – kalite parametresi yok
Embed – API yok, sadece dişli menüye bak

2. vq=hd720 (URL)

Embed URL’ye vq=hd720 gömülü
URL parametresi – dişli menüde başlangıç kalitesine bak

3. vq=hd1080 (URL)

Embed URL’ye vq=hd1080 gömülü
URL parametresi – dişli menüde başlangıç kalitesine bak

4. API setPlaybackQuality

Butonlarla hd720 / hd1080 / small zorlama denemesi
Hazır – önce oynat, sonra butona bas

5. API setPlaybackQualityRange

Range ile min–max kalite aralığı denemesi
Hazır – önce oynat, sonra butona bas

6. Büyük fiziksel iframe (1280×720)

Gerçek 1280px genişlik – boyut etkisi var mı?
Fiziksel 1280×720 – kalite menüsüne bak (küçük ekrandan fark var mı?)
Ne yazacaksın bana?
Örnek: “4’te hd720 butonuna bastım, dişlide hâlâ Auto/480p”, “6’da 720p seçili geldi”, “hiçbiri değişmedi”…
Butonlar API çağrısı yapıyor; değişiklik olursa onPlaybackQualityChange status’ta görünür.
